Overview

This assignment explores the application of AI in software engineering. It covers theoretical understanding, practical coding, automated testing, predictive analytics, and ethical considerations.

Contents

Part 1: Theoretical Analysis
Answers to short questions and a case study on AI in DevOps.

Part 2: Practical Implementation

Task 1: Python function for sorting dictionaries using AI-assisted code completion.

Task 2: Automated login test using Selenium WebDriver.

Task 3: Predictive analytics using Random Forest on Breast Cancer dataset.

Part 3: Ethical Reflection
Discussion on bias and fairness in AI models.

Bonus Task (Optional): AI tool proposal for software engineering challenges.

Tools & Libraries

Python 3.x

Selenium WebDriver

scikit-learn

pandas, numpy

Jupyter Notebook / Google Colab

How to Run

Task 1: Run the Python script sort_dicts.py to test dictionary sorting.

Task 2: Run selenium_login_test.py with ChromeDriver set up for automated login tests.

Task 3: Open the Jupyter Notebook predictive_analytics.ipynb and run cells sequentially.

Notes

The Selenium test uses a demo login page for demonstration purposes.

The predictive analytics task adapts a medical dataset for issue priority prediction.

Ethical reflections included to highlight AI fairness concerns.
